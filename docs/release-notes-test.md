Carriage version 4 — a night train of windows. Test build for Apple Silicon Macs (macOS 12 or later). The Orient-Express release is this same build under its own name.

What's in it
- The clocks are gone. The new tab page is the inside of a Pullman carriage at night: mahogany panelling, brass bands and nameplate, and five arched windows in a row
- One landscape runs past behind all five windows and carries across the piers between them, so the row reads as a single carriage in motion: hills, woods, a lit cottage, telegraph poles and wires, and the lamp reflected in the glass. The nearer a thing is, the faster it goes by
- Flimsy slatted shutters hang in the first four windows, each pulled down as far as the last passenger left it, each leaning its own way and rattling with the car. The last window is left clear, and the moon rides outside it
- Nothing is fetched and nothing is stored: the scene is drawn by the page itself. The weather plaques and their Open-Meteo requests are gone with the clocks, so the new tab page makes no outside connection at all
- The motion stops for anyone who asks their Mac to reduce motion
- Built on Helium 0.19.2.1 / Chromium 155.0.8059.39 (ungoogled-chromium), uBlock Origin included
- Chrome Web Store extensions install and update directly from Google, as in Chrome and Brave

Install
1. Open the .dmg and drag the app into Applications.
2. This build is not yet signed by Apple: the first time, right-click it in Applications and choose Open.
