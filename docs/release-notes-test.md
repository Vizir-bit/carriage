First Chromium-based test build of Carriage for Apple Silicon Macs (macOS 12 or later).

What's in it
- Carriage name, typewriter-key icon, wordmark and logos; walnut and paper default colours
- Built on Helium 0.19.2.1 / Chromium 155.0.8059.39 (ungoogled-chromium), uBlock Origin included
- Chrome Web Store extensions install and update directly from Google, as in Chrome and Brave
- New tab page with three retro wall clocks: London, Paris, Moscow

Install
1. Open the .dmg and drag Carriage into Applications.
2. This build is not yet signed by Apple: the first time, right-click Carriage in Applications and choose Open.
